About Me

I am a QA Automation Engineer with over 4+ years of experience specializing in Tricentis Tosca automation testing across SAP GUI, Fiori, and API environments. I have a strong command of creating dynamic, data-driven, and reusable test scripts using Tosca Test Data Service (TDS), and implementing loops, repetitions, and modular test assets to enhance automation efficiency.

My expertise includes functional and regression testing, API validation, and test lifecycle management through tools like SAP Solution Manager, JIRA, and Azure DevOps. I’m passionate about quality, precision, and automation-driven efficiency — ensuring that critical business operations in the SAP landscape run smoothly and reliably.

My core responsibilities include analyzing business requirements and identifying automation opportunities, developing reusable Tosca modules and automation frameworks, creating TestCase Design structures for data-driven testing, maintaining Execution Lists for batch execution, managing dynamic test data with TDS, executing regression and functional suites, and sharing automation reports to support defect analysis.
